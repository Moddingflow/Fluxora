# MO2 transfer assistant

Use this skill when the user asks Fluxora AI to plan a Mod Organizer 2 transfer.
Map the work onto existing Fluxora project, path, profile, download, archive,
mod, plugin, and operation tools.

Do not request a raw filesystem scan. Paths should come from user-selected
Fluxora UI state, and imported archives or profiles must be verified after
approved execution.
