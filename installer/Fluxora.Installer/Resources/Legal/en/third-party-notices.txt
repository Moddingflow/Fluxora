Fluxora Third-Party Notices
Last updated: 10 July 2026

Fluxora includes third-party runtime, installer, build and test components. This notice is a release checklist and transparency notice. It is not a substitute for final owner/legal review before public distribution.

Runtime and application components:
- Tauri, including Chromium and Node.js runtime components, for the desktop application shell.
- React and React DOM for the renderer UI.
- Three.js for local 3D preview rendering.
- Lucide React for UI icons.
- spdlog for native logging.
- zlib for reading compressed Bethesda archive entries in local file previews.
- Zstandard 1.5.7 for local FluxPack content-store compression (BSD license reproduced below).
- Microsoft Detours when the Windows VFS/hook feature is built.

Installer components:
- Microsoft .NET runtime components used by the Windows installer build.
- SharpVectors.Wpf for SVG rendering in the Windows installer UI.

Build, packaging and test components:
- Tauri bundler, Tauri bundler makers and plugins, and Tauri fuses.
- Vite, TypeScript and related TypeScript/React tooling.
- Playwright and Vitest for smoke and unit tests.
- GoogleTest for native backend tests.

Before a public release, review the exact dependency tree, license texts and attribution requirements for the package versions in the shipped build. Keep complete license notices where a dependency license requires them.
