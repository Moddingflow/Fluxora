When Nexus Mods is connected and an archive does not already have a stable source id, install planning may send the archive's MD5 fingerprint and the selected game's Nexus domain to the Nexus Mods API. This best-effort lookup is used only when it returns one unambiguous mod/file result; failures or ambiguous results fall back to local identity resolution. Fluxora does not send the archive contents, local path or file name for this lookup.

While Nexus Mods is connected, Fluxora may automatically check complete installed Nexus mod/file identities for file-level updates no more than once every 24 hours and may check again when you request it manually. Results, API availability and version labels are supplied by Nexus Mods and may be incomplete, delayed, ambiguous or unavailable; Fluxora applies rate-limit reserves and leaves the previous local result unchanged when it cannot resolve one file safely.

Optional AI assistant features may send your prompt, the selected tab's chat history or structured summary, an unfinished active goal, system/safety instructions, goal- and risk-appropriate typed tool declarations, compact selected-build context, bounded requested text fragments, minimal selected capability data and citations through the Fluxora-managed Supabase AI gateway to Google/Gemini. Answer and inspection goals declare read-only tools; an unambiguously implied repair declares only read-only and reversible tools. The provider key remains server-side. Public web research, when requested, runs as a separate web-only Gemini round. AI output may be incomplete or wrong. Chat, file and web content cannot grant tools, approve changes or widen access. Supported mod, plugin, download, install, profile, setting, project and FluxPack actions remain constrained by typed Fluxora capabilities, opaque references and native verification; Gemini never receives arbitrary computer access or writable absolute paths.

Fluxora AI may automatically apply an explicitly requested repair or an unambiguously implied safe repair through a typed capability. An implied repair is limited to read-only and reversible capabilities; irreversible actions retain their exact native-plan confirmation. File work is limited to one bounded transaction of at most 16 distinct allowlisted text/config files, one mutation per file and 2 MiB of changed text, after native scope, effective-file, revision, read-hash and expected-value checks. Ambiguity or conflict stops without mutation and asks one concrete clarification; a short answer continues the same unfinished goal. File changes are made in the managed `Fluxora AI Overrides` mod, leaving source mods unchanged; a failed file batch rolls back atomically.
