## 2. Область действия и устройство продукта

Эта политика распространяется на Fluxora Setup, Fluxora Updater, настольное приложение Fluxora, его нативную оболочку Rust/Tauri, нативное ядро C++ и описанные ниже опциональные онлайн-интеграции.

Fluxora спроектирована прежде всего как локальное настольное приложение. В продукте нет рекламной аналитики, поведенческого отслеживания и автоматической отправки логов или crash-отчётов. Локальное состояние приложения не передаётся оператору лишь потому, что оно хранится на устройстве. Сетевая обработка происходит при автоматическом обнаружении релизов и когда вы запрашиваете другую онлайн-функцию.

Интерфейс Windows использует установленную в системе Microsoft Edge WebView2 Runtime. Fluxora не поставляет отдельный переносимый браузер. Renderer ограничен интерфейсом продукта и не собирает общую историю браузера.

## 3. Setup, WebView2, установка, восстановление и удаление

Setup обрабатывает системную локаль, выбранный язык интерфейса, путь установки, результат проверки свободного места, настройку ярлыка, принятие Условий использования, подтверждение ознакомления с этой политикой, сведения о принадлежности существующей установки, прогресс, стабильные коды ошибок и один идентификатор операции. Нажатие «Установить» разрешает Setup установить или восстановить встроенный payload, а затем автоматически проверить, загрузить и применить последнюю подписанную stable-версию Fluxora, если она новее. Setup создаёт per-user установку, обычно в `%LOCALAPPDATA%\Programs\Fluxora`, долговечную запись о принадлежности, опциональный ярлык, регистрацию протокола и раздельные локальные installer-, update-, Updater- и operation-логи. Установка из Setup изначально не имеет подписанной квитанции update inventory, поэтому это первое обновление после Setup использует подписанный full package; первое успешное обновление создаёт квитанцию для последующих delta точно соответствующей версии.

Принятие Условий использования и подтверждение прочтения этой политики являются разными действиями. Подтверждение ознакомления с политикой не называется и не используется как согласие на всю обработку данных.

Если WebView2 отсутствует, Setup до создания web-интерфейса показывает нативное объяснение. Только после вашего подтверждения Setup запускает встроенный официальный Microsoft Edge WebView2 Evergreen Bootstrapper. Bootstrapper подключается к Microsoft, чтобы получить runtime для подходящей архитектуры. Microsoft и его поставщики доставки могут получить обычные данные соединения: IP-адрес, время запроса, HTTP/TLS-метаданные, сведения об устройстве или операционной системе, предоставленные bootstrapper, и диагностику загрузки. Fluxora не добавляет в этот запрос содержимое проектов, модов, аккаунтов, чатов, credentials или логов. Offline-установка Fluxora возможна, если подходящий WebView2 Runtime уже присутствует.

Repair и удаление проверяют долговечную запись о принадлежности, установленный executable и текущее состояние Windows-интеграции, а также подписанную квитанцию update inventory, если она уже существует, перед изменением ярлыков или регистрации `moddingflow://`. Staging-, backup-, watchdog-, RunOnce recovery- и rollback-записи сохраняются только на время, необходимое для завершения или восстановления операции; после незавершённого восстановления они могут оставаться до следующей попытки.

## 4. Автоматическое обнаружение, разрешение в Setup и установка из приложения

При запуске Fluxora запрашивает публичный подписанный update manifest и его signature из закреплённых Fluxora assets в GitHub Releases. Пока главное окно приложения запущено, Fluxora повторяет проверку каждые 15 минут и при возврате фокуса в это окно, если с предыдущей проверки прошло не менее пяти минут. Аккаунт GitHub для этих проверок не нужен. GitHub и его поставщики доставки получают обычные данные соединения, включая публичный IP-адрес, время запроса, TLS/HTTP headers и выводимые GitHub сетевые или аппаратные данные. Conditional validators (`ETag` и `Last-Modified`) и два последних проверенных manifest cache records могут храниться локально. Если стартовая проверка завершается ошибкой, допускающей повторную попытку, Fluxora после коротких задержек выполняет до двух дополнительных автоматических фоновых попыток; при них раскрываются те же обычные данные соединения. Отсутствующий manifest до первого релиза считается ошибкой, допускающей повтор, чтобы запущенное приложение смогло обнаружить первый релиз позже.

Primary renderer также поддерживает постоянное WebSocket-соединение с Supabase для закреплённого публичного проекта релизов Fluxora. Он подписывается только на INSERT/UPDATE-сигналы stable-релизов и после каждого подключения или переподключения запрашивает последний stable snapshot. Supabase и его инфраструктурные поставщики получают обычные данные соединения, включая публичный IP-адрес, время соединения и метаданные протоколов TLS/WebSocket. Публичные метаданные релиза содержат только GitHub release ID, stable channel, version, tag и время публикации; сигнал не содержит telemetry, данных аккаунта, проекта, мода, архива или AI. Сигнал считается недоверенным и может только запустить ту же проверку подписанного GitHub manifest; сам по себе он не показывает действие обновления. GitHub polling при запуске, возврате фокуса и каждые 15 минут остаётся fallback при задержке или недоступности Realtime.

После успешных install, repair или update в Setup он выполняет ту же подписанную проверку как часть действия «Установить». Если есть более новая stable-версия, Setup автоматически загружает подписанный full package из GitHub Releases, хранит возобновляемый пакет и проверочные данные в `%APPDATA%\Fluxora\updates` и передаёт их изолированному Updater. При ошибке проверки или загрузки Setup запускает успешно установленную встроенную версию, а Fluxora может повторить проверку по автоматическому расписанию. GitHub и его поставщики доставки получают описанные выше обычные connection metadata. Fluxora не добавляет в запросы данные проектов, модов, архивов, аккаунтов, AI-чатов, credentials, логов, signatures или authorization headers; этот flow не добавляет telemetry.

Вне Setup фоновое обнаружение только выявляет доступное обновление. Загрузка пакета, установка и последующий перезапуск начинаются после выбора действия обновления внутри приложения.

Fluxora проверяет подпись manifest и хэши файлов/пакетов. Full/delta packages, manifests, signatures и inventories являются публичными машиночитаемыми release data, а не запускаемой portable-дистрибуцией. Локальные staging, backup, health acknowledgement, rollback и recovery data нужны для надёжного выполнения запрошенного обновления.

## 5. Данные, обрабатываемые локально

В зависимости от используемых функций Fluxora может локально обрабатывать или хранить:

- путь установки, установленную версию, долговечную запись о принадлежности, подписанную квитанцию update inventory после её создания, ярлыки, принадлежность protocol registration, recovery state и operation IDs;
- язык, тему и настройки приложения, выбранные пути к играм и инструментам, конфигурацию проектов и профилей, порядок plugins, определения executables и другие предпочтения;
- имена проектов, build folders, mod folders, game paths, archive metadata, download entries, импортированные manager data, локальные file inventories, hashes, conflict information, deployment state и историю установки;
- архивы и sidecar records в защищённом дереве `Downloads`, включая source IDs, ожидаемый размер, SHA-256, состояние возобновляемой загрузки и результаты установки;
- профиль и состояние подключения ModdingFlow, а также состояние подключения Nexus Mods, как указано в разделе 6;
- вкладки AI-чата, structured continuation summaries, opaque file references, запрошенные фрагменты текста, tool events, источники, run/operation IDs и локальные rollback checkpoints при использовании AI;
- состояние разрешения микрофона, временные audio buffers, локальные speech models и транскрипт локального распознавания речи;
- раздельные логи installer, updater, UI, Rust shell/bridge, native core, operations и crashes. Они могут содержать timestamps, operation IDs, phases, errors, file names, выбранные paths, process information и diagnostics. Путь может косвенно содержать имя учётной записи Windows.

Fluxora намеренно не собирает данные платёжных карт, рекламные идентификаторы, адресные книги, точную геолокацию, изображение камеры или общую историю браузера.

## 6. Credentials и интеграции аккаунтов

### ModdingFlow

При подключении ModdingFlow Fluxora использует authorization-code flow с PKCE в системном браузере. Временные verifier, state и nonce существуют только во время незавершённого входа. Приложение может получить стабильный UUID аккаунта, публичные поля профиля, выданные scopes, срок действия и tokens, необходимые для подключения. Access- и ID-tokens остаются в памяти процесса. Ротируемый refresh credential хранится в Windows Credential Manager под отдельной целью Fluxora и удаляется при отключении аккаунта или после подтверждения сервером его недействительности.

Когда вы открываете каталог ModdingFlow, запрашиваете install plan или download, Fluxora отправляет необходимые для операции идентификаторы и параметры. Приложение может получить идентификаторы игры, мода, версии и артефакта, dependency results, grants, job IDs, expiry, byte size, hashes и короткоживущие signed transport URLs. Signed URL используется в памяти для запрошенной передачи и не считается постоянной идентичностью файла.

Для артефакта, зарегистрированного как ссылка на внешнего provider, ModdingFlow вместо этого может вернуть проверенные сервером identity provider, revision ссылки и provider download URL. После подтверждения install plan Fluxora подключается напрямую к названному provider или его CDN и может передавать обычные metadata соединения и ограниченные HTTP Range-запросы. Fluxora не добавляет к такой передаче ModdingFlow token, credentials provider или browser fallback. Стабильные provider/reference IDs, ожидаемый размер, SHA-256 и состояние возобновляемой передачи могут храниться локально; provider URL остаётся транспортной деталью в памяти и не считается постоянной идентичностью файла.

### Nexus Mods

При подключении Nexus Mods Fluxora может обрабатывать display name, user ID, token type и expiry, OAuth access/refresh tokens либо personal API key. Постоянные secret values защищаются средствами защиты данных Windows, когда они доступны. Приложение отправляет в Nexus Mods game domain, относящиеся к операции mod/file IDs и запрошенный API method.

Если у архива нет стабильного source ID, Fluxora может отправить его MD5 fingerprint и выбранный Nexus game domain, чтобы запросить однозначное сопоставление mod/file. Archive contents, local path и local filename для этого запроса не отправляются. IDs установленных Nexus files могут проверяться на обновления не чаще одного раза за 24 часа и повторно по вашему запросу. Возвращённые version, availability, timestamp, quota и retry metadata могут кэшироваться локально. Cache records, не использовавшиеся 90 дней, удаляются.

## 7. AI, web-исследование и голосовой ввод

AI-функции опциональны и запускаются только при их использовании. Запрос может содержать отправленное вами сообщение, выбранную историю чата или structured continuation summary, незавершённую цель или состояние уточнения, provider/model metadata, typed capability declarations, компактные metadata выбранного build и ограниченные text excerpts, необходимые для задачи. Fluxora по возможности использует opaque references и relative paths и не предоставляет модели произвольный доступ к filesystem или shell.

Управляемые AI-запросы могут проходить через gateway Fluxora и затем в Google/Gemini. Если запрошено публичное web-исследование, provider может обработать search query и публичные источники в отдельном research round. Ответы provider и grounding sources считаются недоверенными данными и сами по себе не могут разрешить локальное изменение. Provider и его subprocessors могут обрабатывать данные за пределами ЕС/ЕЭЗ по собственным privacy terms и механизмам передачи.

Запись голоса требует явного действия пользователя и краткоживущего permission gate. Аудио обрабатывается локально встроенными Whisper и Silero VAD. Raw microphone audio не загружается функцией распознавания. Только транскрипт, который вы решите отправить, становится частью AI-request.

Не включайте без необходимости персональные данные, secrets, конфиденциальную информацию третьих лиц или специальные категории данных в AI prompts, импортированный текст, file names или support materials.

## 8. Логи, crash data, cache и сроки хранения

Логи и crash diagnostics остаются локальными, если вы сами ими не поделитесь. Текущие builds не загружают их автоматически и не устанавливают автоматический срок удаления; они остаются, пока вы их не удалите, не сбросите приложение, не удалите соответствующие application data или пока их не удалит очистка системы.

Settings, projects, profiles, archives, download history, sidecars и AI sessions остаются, пока вы не удалите соответствующий объект, не сбросите приложение или не удалите относящиеся к нему данные. Закрытие или удаление AI chat удаляет его из Fluxora AI session store; отдельные reset actions удаляют соответствующие локальные rollback checkpoints. Storage caps могут удалять целиком более старые rollback runs.

Access- и ID-tokens, хранящиеся только в памяти, удаляются при завершении соответствующего процесса. Сохранённый refresh credential остаётся до disconnect, invalidation, replacement, reset или удаления соответствующей записи Windows. Update download, staging, backup, watchdog и recovery data удаляются после обычного успешного завершения; прерванные recovery materials могут оставаться до успешного восстановления или ручного удаления после завершения Fluxora. Update manifest cache хранит не более двух проверенных records. Nexus update cache records, не использовавшиеся 90 дней, удаляются.

Сторонние сервисы сами определяют серверные сроки хранения. Изучите их privacy statements и account controls.

## 9. Цели и правовые основания

С учётом обязательной проверки немецким юристом предполагаются следующие основания статьи 6 GDPR:

- статья 6(1)(b): установка, работа, запрошенная установка обновления, запрошенное подключение аккаунта, downloads, AI responses и другие функции, необходимые для предоставления выбранной пользователем software service;
- статья 6(1)(f): безопасность, integrity verification, локальная диагностика, предотвращение злоупотреблений, надёжное восстановление и описанные выше ограниченные автоматические проверки обновлений. Законные интересы состоят в поддержании безопасного и совместимого приложения и диагностике ошибок;
- статья 6(1)(a): только когда конкретный опциональный flow явно запрашивает согласие и определяет охватываемую обработку. Согласие можно отозвать на будущее;
- статья 6(1)(c): обработка, необходимая для выполнения применимой юридической обязанности.

Локальное хранение и доступ, строго необходимые для явно запрошенной desktop-функции, предполагается относить к исключению § 25(2) TDDDG. Fluxora не использует local storage для рекламного tracking. Эта оценка входит в обязательную юридическую проверку.

## 10. Получатели и международные передачи

В зависимости от действия получателями могут быть Microsoft для доставки WebView2; GitHub и его CDN providers для update checks/downloads; Supabase и его infrastructure providers для публичного release-signal WebSocket и snapshot; ModdingFlow и его infrastructure providers для account, catalogue, API и download functions; Nexus Mods для account/API functions; Google/Gemini и managed AI gateway для отправленных AI requests и web research; а также download host или сайт, который вы явно открываете.

Эти поставщики действуют по собственным условиям и privacy notices. GitHub указывает, что может обрабатывать данные в США и других странах и обычно использует признанные механизмы передачи, такие как Standard Contractual Clauses ЕС, для стран без решения об адекватности. Точные роли, providers и safeguards должны быть подтверждены до публичного выпуска.

Fluxora не продаёт персональные данные и не отправляет автоматически оператору telemetry, logs, crash files, projects, mods или AI histories.

## 11. Ваш выбор и права

Вы можете отказаться от загрузки WebView2, отменить post-install проверку или загрузку в Setup до commit передачи Updater (после этого запускается встроенная установка), отклонить доступное обновление внутри приложения, отключить optional accounts, не использовать или прекратить AI/microphone functions, удалить chats/checkpoints, projects/caches и credentials, а также удалить приложение.

Когда применяется GDPR и выполнены его условия, у вас могут быть права на доступ, исправление, удаление, ограничение, переносимость, возражение и отзыв согласия. Поскольку большая часть данных Fluxora локальна, многие действия выполняются непосредственно на вашем устройстве. Для данных у контролёра или вопросов используйте контакты раздела 1.

Вы можете подать жалобу в компетентный орган по защите данных, в частности в государстве ЕС вашего обычного места жительства, работы или предполагаемого нарушения.

## 12. Безопасность

Fluxora применяет подписанные manifests/packages, ограниченные native interfaces, ownership checks, защиту Windows credentials для текущего пользователя, локальные access controls, allowlisted network destinations и transaction recovery. Ни одна мера не устраняет все риски. Защищайте Windows account, backups, game data, credentials и installation directory и получайте Fluxora только из официального канала.
