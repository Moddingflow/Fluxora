# Flag icons

These SVG country flag emoji assets are original Twemoji SVG files from
`jdecked/twemoji`:

- `flag-united-kingdom.svg`: `assets/svg/1f1ec-1f1e7.svg`
- `flag-russia.svg`: `assets/svg/1f1f7-1f1fa.svg`
- `flag-germany.svg`: `assets/svg/1f1e9-1f1ea.svg`

They replace the temporary hand-authored SVG flags that were previously stored
under `frontend-tauri/src/renderer/assets/images/`.
